# PC CONTROL

Небольшая веб-панель для управления Windows-ПК с телефона или другого устройства в локальной сети: громкость, музыка (Windows GSMTC), обложки треков, мониторинг CPU/RAM и кнопка хоткея Discord.

> **Только для Windows.** Для доступа с телефона сервер и телефон должны быть в одной сети Wi‑Fi/LAN.

---

## Возможности

- 🔊 Системная громкость: ползунок и кнопки `−`/`+`.
- 🎵 Управление музыкой: предыдущий / play‑pause / следующий трек, название, исполнитель, обложка.
- 🎤 Кнопка Discord: отправляет hotkey **NumPad +** (сервер не знает реальное состояние микрофона).
- 📊 Мониторинг CPU / RAM / занято RAM.
- 🟢 Индикатор подключения, ввод токена прямо в интерфейсе (токен сохраняется в браузере).

---

## Установка

Нужен **Windows 10/11** и **Python 3.10+** (при установке отметьте «Add Python to PATH»).

Самый простой способ — двойной клик по **`start.bat`**: он сам создаст виртуальное окружение, поставит зависимости и запустит сервер.

Вручную:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python server.py
```

Откройте в браузере: **http://127.0.0.1:5000**

## Доступ с телефона (LAN)

По умолчанию сервер слушает только `127.0.0.1`. Чтобы открыть панель с телефона:

```powershell
# 1) придумайте длинный случайный токен (или сгенерируйте):
python -c "import secrets; print(secrets.token_urlsafe(32))"

# 2) задайте переменные окружения в этом же окне PowerShell:
$env:PC_CONTROL_HOST = "0.0.0.0"
$env:PC_CONTROL_PORT = "5000"
$env:PC_CONTROL_TOKEN = "ВСТАВЬТЕ_СГЕНЕРИРОВАННЫЙ_ТОКЕН"

# 3) запустите
python server.py
```

Затем откройте `http://<IP-ПК-в-LAN>:5000` на телефоне и введите этот токен в поле **«Токен сервера»** → **«Подключить»**.

IP ПК можно узнать командой:

```powershell
ipconfig
```

(ищите `IPv4-адрес` у активного адаптера, обычно `192.168.x.x`).

**Без `PC_CONTROL_TOKEN` LAN-режим не запустится** — это специальная защита (токен должен быть не короче 24 символов).

---

## Важно про безопасность

- Не публикуйте токен в интернете, чатах и скриншотах. Он даёт полный доступ к управлению ПК.
- Не пробрасывайте сервер в интернет без авторизации и TLS. Проект предназначен **только для локальной сети**.
- API принимает запросы только с локальных/приватных IP; для изменений проверяется `Origin`.
- Токен хранится только в браузере (`localStorage`) и в переменной окружения сервера. Файл `pc_control_token.txt` в репозиторий не входит.

## Кнопка микрофона Discord

Кнопка просто посылает клавишу **NumPad +** через Windows API (`SendInput`, при блокировке — `keybd_event`). Поэтому:

1. В Discord назначьте хоткей на **NumPad +** (Mute / Toggle Mute — как вам нужно).
2. Запустите Discord и `server.py` **с одинаковыми правами** (оба обычные или оба от администратора). Иначе Windows может блокировать синтетический ввод.
3. Античиты (например, **FACEIT Anti‑Cheat**) могут полностью блокировать программный ввод — в этом случае кнопка не сработает. Это ограничение защиты, а не ошибка панели.

Ответ сервера честно показывает результат: `ok: true` — клавиша доставлена, `hotkey_blocked_by_windows` — ввод заблокирован системой.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PC_CONTROL_HOST` | `127.0.0.1` | Адрес прослушивания. `0.0.0.0` — доступ из LAN |
| `PC_CONTROL_PORT` | `5000` | Порт |
| `PC_CONTROL_TOKEN` | пусто | Секрет для LAN-режима (обязателен, ≥24 символов) |

## Если что-то не работает

- **Страница не открывается** — проверьте, запущен ли `server.py` и не занят ли порт 5000 другим процессом. Можно сменить порт через `PC_CONTROL_PORT`.
- **Нет соединения / Неверный токен** — проверьте токен в поле на странице и переменную `PC_CONTROL_TOKEN` на сервере.
- **Музыка не отображается** — должен быть активен плеер, и медиа API Windows должен быть доступен; поддержка зависит от плеера.
- **Обложка не грузится** — Windows иногда тормозит чтение thumbnail; сервер сохраняет состояние в `/status` (`cover_reader`) и не spam-ит повторные запросы.
