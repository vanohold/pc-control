## Развёрнутое описание (можно вставить в начало README.md)

**PC CONTROL** — компактная веб-панель для управления Windows-ПК с телефона или другого устройства в локальной сети.

Что умеет:

- 🔊 менять системную громкость ползунком и кнопками `−` / `+`;
- 🎵 управлять музыкой через медиа API Windows: предыдущий трек, play/pause, следующий, название, исполнитель и обложка;
- 🎤 отправлять хоткей Discord (NumPad `+`) одной кнопкой;
- 📊 показывать загрузку CPU, RAM и объём занятой памяти;
- 🟢 отображать состояние подключения и запрашивать токен прямо в интерфейсе.

По умолчанию панель доступна только на самом ПК (`127.0.0.1:5000`). Для доступа с телефона нужно явно включить LAN-режим и задать длинный токен — без него сервер откажется запуститься. Данные плеера и обложки читаются через Windows GSMTC, громкость — через `pycaw`, поэтому проект работает только на Windows.

Установка на Windows состоит из одного двойного клика по `start.bat`: он сам создаст виртуальное окружение, установит зависимости и запустит сервер. Дальше достаточно открыть `http://127.0.0.1:5000`.

> Проект предназначен для домашней локальной сети. Не публикуйте токен и не открывайте сервер в интернет без дополнительной защиты.
